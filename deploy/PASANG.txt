PEMASANGAN CPOS PLATFORM (CPOS + RekapIn + Analytics + Deteksi Plat)
=====================================================================

Kebutuhan PC tujuan
- Windows 10 / 11 64-bit, akun administrator, internet (sekali, untuk memasang Python & library)
- Bisa terhubung ke SQL Server yang tertulis di backend\.env
- Python 3.11 dan ODBC Driver 18 for SQL Server: dipasang otomatis lewat winget bila belum ada

Isi zip
     backend\                   semua kode (CPOS + RekapIn, Analytics, Deteksi Plat) dan backend\.env
     frontend\cpos\             templates & static CPOS
     frontend\analytics\dist\   tampilan Analytics
     deploy\, jalankan.*        skrip pasang dan jalankan

Memasang
1. Ekstrak zip ini ke folder tetap, mis. C:\CPOS-Platform (jangan di Downloads / Desktop).
   Memperbarui dari versi lama (folder CPOS\, Analytics\, Deteksi\): pakai paket lengkap (buat_paket.bat -Penuh), ekstrak ke folder
   baru, salin pengaturan lama ke backend\.env (lihat backend\.env.example), lalu jalankan pasang.bat dari folder baru.
2. Periksa backend\.env bila PC tujuan berbeda jaringan / server: database (DB_*, ANALYTICS_DB_*), PORT (port web),
   DETEKTOR_PORT / URL_DETEKTOR (port internal Deteksi Plat).
3. Klik kanan deploy\pasang.bat > Run as administrator.
   Pertama kali memasang library Python (10-20 menit). Selesai bila muncul alamat CPOS berwarna hijau.
4. Buka http://<IP PC ini>:<PORT> dari PC lain di jaringan kantor. Hanya port itu yang dibuka di firewall;
   Analytics (8001) dan Deteksi Plat (DETEKTOR_PORT) hanya dipakai di dalam PC ini.

Sesudah terpasang
- CPOS menyala sendiri setiap Windows menyala (tugas terjadwal "CPOS Platform", akun SYSTEM, tanpa perlu login),
  dan dinyalakan ulang otomatis bila berhenti.
- Log: C:\ProgramData\CPOS-Platform\cpos-platform\log
- Memperbarui aplikasi: ekstrak zip versi baru ke folder yang sama (timpa), lalu jalankan pasang.bat lagi.
  Zip bernama CPOS-Platform-perubahan-... hanya berisi file yang berubah. Pasang berurutan, jangan ada yang terlewat.
- Menghentikan sementara: Task Scheduler > CPOS Platform > End.
- Mencopot: klik kanan deploy\copot.bat > Run as administrator.


HTTPS (supaya unduhan Excel tidak diblokir browser)
1. Letakkan caddy.exe di folder deploy.
2. Sebagai Administrator: powershell -ExecutionPolicy Bypass -File pasang_https.ps1 -IpServer <IP server> -Akar <folder aplikasi> -Port 8080
3. Restart CPOS dan Analytics.
4. Pasang root.crt yang ditampilkan skrip ke Trusted Root di tiap PC pengguna. Firefox: aktifkan security.enterprise_roots.enabled.
5. Pengguna membuka https://<IP server>/ . Alamat http port lama tidak lagi terbuka dari jaringan.
